论坛规则

本规则适用于论坛内所有板块及私信交流。请在发帖、回复或发送私信前阅读并遵守。

真实记录 尊重交流 尊重版权 生态友好

目录

一、总则 二、发帖规范 三、交流礼仪 四、站务权限与责任 五、违规处理 六、用户权利 七、附则 板块专属规则
一

总则

  1. 主题定位：本论坛为「东方 Project × 观鸟」同人社区，鼓励讨论东方 Project 相关创作、现实世界鸟类观察与自然记录。
  2. 尊重为先：互相尊重、友好交流是社区基石。禁止人身攻击、引战和歧视性言论。
  3. 遵守法律：不得发布违法、色情或侵犯他人权益的内容。严重违规内容经核实后可直接删除内容和账号。
二

发帖规范

1. 板块选择

  • 请根据帖子内容选择正确板块；「观鸟记录」仅发布现实鸟类观察，「东方鸟类考据」用于讨论东方设定、原型与相关资料。
  • 观鸟记录中的鸟种名称须对应现实中存在的鸟类；东方角色、幻想物种与同人设定请发布到东方相关板块。

2. 内容要求

  • 标题应清晰，正文应包含实质内容；避免“顶”“好”等无意义灌水。
  • 鼓励原创；转载须注明来源，并确保已获得原作者许可。
  • 禁止刷屏、重复发帖与恶意挖坟。

3. 观鸟记录特别规范

  • 必须填写鸟种名称，并标明观察地点。
  • 记录须基于实际观察；建议补充时间、天气、行为描述等信息。
  • 涉及珍稀物种时，不宜公开巢址、栖息点等过于精确的位置。
  • 禁止发布诱拍、巢穴骚扰、伤害鸟类等不文明观鸟行为的记录。

4. 东方 Project 同人创作

  • 可发布绘画、小说、音乐、游戏等二次创作；请标注作者及授权状态。
  • 禁止发布 R18、无授权转载、侵权或抄袭内容。
三

交流礼仪

  1. 友善讨论：包容不同观点，理性交流；禁止人身攻击、辱骂和阴阳怪气。
  2. 禁止引战：不得挑起东方 Project 角色或作品间的对立，也不得恶意比较现实鸟类或观鸟器材。
  3. 私信规范：私信同样受本规则约束；禁止骚扰、广告和恶意信息。
  4. 语言规范：请使用文明、清晰的表达。
四

站务权限与责任

  1. 站长：负责站务体系与管理员任免；站长为唯一最高站务身份。
  2. 管理员：维护社区秩序、处理违规内容并解答用户疑问。
  3. 内容管理：站长和管理员可编辑、置顶或删除违规帖子，删除违规回复，并处理普通用户的禁言与账号状态。
  4. 行为规范：站务人员应公正执行规则，不得滥用职权。用户对处理结果有异议时，可私信其他站务人员申请复核。
五

违规处理

违规情形处理措施
轻微违规，如发错板块、轻微灌水警告提醒，移动或删除帖子
多次违规或较严重违规，如引战、轻度人身攻击视情况禁言 1 至 7 天
严重违规，如辱骂、歧视、违法内容、恶意刷屏永久禁言或删除账号
广告或骚扰私信直接永久禁言
  • 处理流程：通常先警告，再逐步升级；严重违规除外。
  • 禁言时长：站务人员可按严重程度设置 1 小时、6 小时、12 小时、1 天、7 天或永久禁言。
  • 申诉与复核：用户可在禁言期内通过站内私信联系其他站务人员申诉；重要管理操作应保留可复核记录。
六

用户权利

  1. 发言权：状态正常的用户可发帖、回复和发送私信，但须遵守本规则。
  2. 申诉权：对站务处理有异议时，可向其他站务人员申请复核。
  3. 隐私保护：论坛不会主动泄露用户个人信息；头像、自我介绍等公开资料由用户自行决定。
  4. 建议反馈：欢迎在「综合讨论」板块发帖或私信站务人员提出建设性意见。
七

附则

  1. 本规则自发布之日起生效；修订时会提前公告。
  2. 最终解释权归管理组所有。
  3. 未尽事宜由管理组共同讨论后处理。

Board-specific Guidelines

板块专属规则

以下规则是论坛总则的补充。请在对应板块发帖前阅读。

01

综合讨论

主题：东方 Project、观鸟、ACG 文化、自然观察等广泛话题。

  • 允许：日常交流、资讯分享、求助提问、活动组织。
  • 禁止：无意义水帖、广告和刷屏。
  • 鼓励：高质量讨论、干货分享和新人引导。
02

观鸟记录

主题：现实世界中的观鸟报告、物种辨识和观察心得。

  • 必须填写鸟种中文名，记录须基于实际观察。
  • 建议填写至少到城市级的地点；珍稀物种不宜公开精确位置。
  • 建议填写时间、天气和行为特征；照片须为真实拍摄。
  • 禁止诱拍、巢穴干扰、伤害鸟类；未经证实的稀有鸟种记录应附证据。
03

东方鸟类考据

主题：东方 Project 的设定、角色、音乐、世界观及鸟类或民俗原型考据。

  • 允许：深度分析、设定挖掘、考据讨论和新旧作对比。
  • 禁止：无依据的设定拼凑、恶意曲解及无关政治或宗教内容。
  • 鼓励：引用官方资料、附来源链接并理性讨论。
04

绘画与创作

主题：东方 Project 及观鸟相关的绘画、小说、音乐、视频、手作等原创或授权作品。

  • 原创作品建议在标题标注「原创」；转载须标注「转载」、原链接及授权情况。
  • 禁止 R18、血腥暴力、政治敏感、盗图或抄袭内容。
  • 鼓励交流技法并接受善意批评。
05

摄影交流

主题：观鸟摄影、自然摄影、风光摄影和设备讨论。

  • 照片须为本人拍摄；授权转载须注明来源和授权情况。
  • 建议注明设备、拍摄参数及地点。
  • 请说明明显超出常规校正范围的后期处理。
  • 禁止违背生态伦理的诱拍、投食拍摄等行为。
06

东方二次同人

主题：东方 Project 的同人游戏、音乐、小说、漫画，以及东方二次同人角色和连缘 Project 相关内容。

  • 请注明作者、社团及贩售信息（如有），并尊重版权。
  • 禁止发布未经授权的商业同人作品下载链接。
  • 可开展作品推荐、评测与汉化讨论。
  • 禁止 R18、侵权或抄袭内容；鼓励支持原创作者并理性评价。
生效说明

本版规则由管理组发布；后续修订将在论坛内公告。
